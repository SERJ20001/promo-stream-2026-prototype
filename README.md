# Промо-стрим 2026

Интерактивная HTML/CSS/JS-вёрстка макетов под экран iPhone 13 размером 375 × 812 пикселей.

Постоянная ссылка: https://serj20001.github.io/promo-stream-2026-prototype/

## Запуск

Из папки проекта:

```bash
python3 -m http.server 8000
```

Открыть: http://127.0.0.1:8000/prototype/

## Состав

- `prototype/index.html` — семантическая разметка экранов и шторок.
- `prototype/styles.css` — размеры, отступы, цвета, типографика и анимации.
- `prototype/app.js` — переключатели, выбор параметров, расчёты и переходы.
- `assets/fonts/` — локальные начертания Avito Sans Text из предоставленного архива.
- `assets/*.svg` — интерфейсные иконки, экспортированные из исходных узлов Figma.
- `assets/*.png` — фотографии и составные иллюстрации, выгруженные цельными изображениями из конкретных узлов Figma без пересборки слоями.

Цельные снимки экранов в интерфейсе не используются.
